中国大陆两人的小微企业（以深圳公司为例），完全可以实现全程远程线上办理变更法定代表人，不需要本人亲自前往线下窗口办理。
深圳目前对内资企业变更提供了非常成熟的“全流程网上办理”渠道，您只需要通过[深圳市市场监督管理局（深圳市知识产权局）官网](https://amr.sz.gov.cn/xxgk/qt/ztlm/ssdjzc/blsm/blfw/index.html)（商事主体登记注册“开办企业一窗通”系统）提交申请，通过线上电子签名即可完成。
以下是具体的远程操作方法和核心步骤：
## 🖥️ 远程线上办理核心条件
实现全流程远程办理，最关键的是电子签名。线上提交申请后，以下人员必须在手机端完成实名认证并进行电子签名：

   1. 您本人（作为原法人、股东或签字人）
   2. 您的亲属（作为新任法人）
   3. 公司另一位股东（两人公司，修改章程和股东会决议需要股东签字认可）
   4. 经办人（负责在系统上填报资料的人，可以是您或亲属任意一人）

注：签名人员需提前下载“深圳登记注册”APP 或使用微信小程序“深i企”，并准备好个人银行卡（用于实名核验）或个人数字证书。
------------------------------
## 📝 两人公司法人转亲属的完整流程
两人的有限责任公司变更法人，涉及“股东会决议”和“章程修正案”。基本流程如下：
## 1. 系统填报申请

* 经办人登录 深圳市市场监督管理局商事登记系统。
* 选择“商事主体变更登记”，输入公司统一社会信用代码。
* 在变更事项中勾选“法定代表人变更”。
* 填入新法人（您的亲属）的姓名、身份证号、内地手机号、邮箱等信息。
* 

## 2. 生成并签署电子文件

* 填报完成后，系统会自动生成标准模板文件，包括：
* 《公司登记（备案）申请书》
   * 《股东会决议》（同意免去原法人职务，选举新法人职务）
   * 《公司章程修正案》（修改其中关于法人的条款）
* 提交后，系统会生成待签名的流水号。所有相关人员（新老法人、全体股东）打开“深圳登记注册”APP 或特定电子签名渠道，进行刷脸实名认证并电子签名。
* 

## 3. 后台审核与换发执照

* 所有人签名完成后，系统正式提交给工商局后台人工审核。
* 深圳的审核速度非常快，通常 1 - 3 个工作日 即可出结果。
* 审核通过后，公司的新营业执照可以选择邮寄递送到家（需支付快递费），或者由新法人在深圳本地的政务自助机上打印，无需人工窗口排队。
* 

------------------------------
## ⚠️ 特别注意事项

   1. 关于股权是否一同转让：如果只是单纯换“法人”，您不卖公司，您原本的股权可以不用动；如果是把“老板”彻底让给亲属，则需要同时勾选“股权变更（转让）”，流程基本一致，同样可以远程电子签名办理。
   2. 税务与银行变更：工商变更完成后，并不意味着全部结束。新法人必须通过税务系统进行实名认证（通常可在电子税务局远程完成）。另外，公司的银行基本户也需要变更法人，银行通常要求新法定代表人必须本人携带身份证、新执照和公章亲自前往开户行柜台办理。
   3. 失信限制：请确保新法人（您的亲属）征信正常，没有被列为失信被执行人或在其他被吊销公司担任过法人，否则系统审核无法通过。

如果您想具体了解或直接开始办理，可以直接登录 深圳市市场监督管理局官网 查看最新的全流程无纸化业务指南。
为了给您更精准的建议，请问您的亲属是否持有中国大陆居民身份证？以及除了变更法人，您是否打算连同股权一起转让给这位亲属？
